### 🔍 Project Highlights

<details>
<summary><b>✈️ FlyCombi — Airline Route Analysis System</b></summary>

- Analyzes airline routes using advanced graph algorithms to find optimal city-to-city paths.
- Evaluates airport centrality and importance within complex networks.
- Supports constraint-based itinerary planning and dynamic exporting to **KML format**.
</details>

<details>
<summary><b>🛫 Algueiza Flight System — High-Performance Flight Manager</b></summary>

- Built from scratch in **Go** using custom memory-efficient data structures (**BST**, **Min/Max Heaps**, **HashMaps**).
- Implements real-time filtering, priority queues, and range queries under strict $O(\log n)$ runtime targets.
</details>

<details>
<summary><b>🔐 Base64 Encoder / Decoder — x86-64 Assembly & C Interface</b></summary>

- Low-level implementation built for *Organización del Computador*.
- Reads binary data directly, handles padding rules, and provides a clean C API interface for encoding/decoding.
</details>

<details>

- **Testing:** Automated BDD specs using **Gherkin**.
</details>

<details>
